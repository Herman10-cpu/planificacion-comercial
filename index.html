⚙️ Configuración Google Calendar

Seguí estos 3 pasos para activar la integración real

🔑 Para activar la integración real necesitás tu Client ID de Google

Esta app usa la API oficial de Google Calendar. Para conectarla necesitás crear un proyecto en Google Cloud Console (gratis, 5 minutos).

📋 Pasos de Configuración
1
Ir a Google Cloud Console
Entrá a console.cloud.google.com e iniciá sesión con tu cuenta Google de empresa. Creá un nuevo proyecto llamado Planificacion-Comercial.
2
Activar la API de Google Calendar
En el menú izquierdo andá a APIs y servicios → Biblioteca, buscá Google Calendar API y hacé clic en Habilitar.
3
Crear credenciales OAuth2
Andá a APIs y servicios → Credenciales → Crear credencial → ID de cliente OAuth. Elegí tipo Aplicación web. En Orígenes autorizados ingresá la URL donde corrés esta app (ej: https://claude.ai o tu dominio). Copiá el Client ID generado.
4
Configurar pantalla de consentimiento
En APIs y servicios → Pantalla de consentimiento OAuth, completá nombre de la app (Planificación Comercial), correo de soporte, y agregá el scope https://www.googleapis.com/auth/calendar.events.
5
Pegá tu Client ID acá abajo y guardá
